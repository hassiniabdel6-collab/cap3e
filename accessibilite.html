CAP 3e

Accessibilité
Cette page est une déclaration de transparence, pas une déclaration de conformité totale. Cap 3e est un projet porté par un seul enseignant. Nous décrivons honnêtement ce qui est en place et ce qui reste à améliorer.

1. Engagement

Cap 3e est destiné à tous les élèves de 3e, y compris ceux qui présentent des besoins particuliers. L'accessibilité n'est pas une contrainte technique : c'est une exigence pédagogique.

L'objectif est de progresser vers une conformité au RGAA (Référentiel Général d'Amélioration de l'Accessibilité) niveau AA, dans la mesure des ressources disponibles pour un projet porté individuellement.

2. Ce qui est déjà en place

  • OK Site entièrement en HTTPS
  • OK Langue déclarée (lang="fr") sur toutes les pages
  • OK Balises <meta viewport> présentes — site responsive mobile
  • OK Titres de pages (<title>) descriptifs sur toutes les pages
  • OK Contrastes de couleurs globalement satisfaisants (texte sombre sur fond clair)
  • OK Police Atkinson Hyperlegible utilisée sur la page Besoins spécifiques (police conçue pour les DYS)
  • OK Liens externes signalés (attributs target="_blank")
  • OK Aucun contenu audio ou vidéo automatique
  • OK Navigation possible sans JavaScript pour le contenu principal

3. Ce qui est partiellement en place

  • Partiel Textes alternatifs sur les images — présents sur certaines pages, à compléter
  • Partiel Structure des titres (H1, H2, H3) — cohérente sur la plupart des pages, à vérifier sur toutes
  • Partiel Accessibilité au clavier — la navigation principale est possible, les composants interactifs (CAPilot) sont à améliorer
  • Partiel Formulaires — les labels sont présents, les messages d'erreur sont à rendre plus explicites

4. Ce qui n'est pas encore en place

  • À faire Déclaration RGAA formelle
  • À faire Audit d'accessibilité complet par un outil ou un expert
  • À faire Lecteur d'écran testé (NVDA, VoiceOver)
  • À faire Bannière de consentement aux cookies accessible
  • À faire Mode contraste élevé ou thème sombre

5. Technologies utilisées

Le site est construit en HTML5, CSS3 et JavaScript vanilla (sans framework lourd). Cette approche favorise la légèreté, la compatibilité et l'accessibilité de base.

6. Signaler un problème

Si tu rencontres une difficulté pour accéder à une page ou utiliser un outil de Cap 3e, tu peux le signaler à :

hassinicap3e@gmail.com

Chaque retour est pris en compte pour améliorer le site.
