Étapes pour activer Google Analytics 4
1
Aller sur analytics.google.com → Créer un compte → Ajouter une propriété GA4 pour hassiniabdel6-collab.github.io/cap3e
2
Copier l'identifiant de mesure (format G-XXXXXXXXXX)
3
Remplacer toutes les occurrences de G-XXXXXXXXXX dans chaque fichier HTML par votre identifiant réel
4
Les données apparaîtront dans GA4 sous 24 à 48h après la première visite
→ Ouvrir Google Analytics
💡 Les données de navigation sont anonymisées (anonymize_ip: true). Aucune donnée personnelle des élèves n'est collectée.
Étapes pour activer Google Search Console
1
Aller sur search.google.com/search-console → Ajouter une propriété → URL prefix → coller https://hassiniabdel6-collab.github.io/cap3e/
2
Choisir la méthode "Balise HTML" → copier la balise fournie (format <meta name="google-site-verification" content="...">)
3
Dans chaque fichier HTML, remplacer le commentaire <!-- <meta name="google-site-verification"... --> par la vraie balise (retirer les <!-- et -->)
4
Soumettre le sitemap : dans Search Console → Sitemaps → coller sitemap.xml
→ Ouvrir Search Console
